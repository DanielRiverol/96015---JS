# 📚 Comisión 96015 - Repositorio de Clase

¡Bienvenidos al repositorio oficial de la **Comisión 96015**! Este espacio está diseñado para centralizar todo el material práctico, ejemplos de código y ejercicios que vayamos desarrollando a lo largo de nuestra cursada.

## 🚀 Dinámica de actualización

Este repositorio es un ente vivo. **Clase a clase**, se irá subiendo el contenido visto en el aula:

* Ejemplos prácticos explicados.
* Resolución de desafíos en vivo.

>❗️ **Fecha de caducidad:** Para mantener el orden de los recursos, este repositorio será **dado de baja permanentemente 20 días después** de finalizado el curso.

---

## ¿Cómo conservar el material?

Si quieres conservar todo el código para tus futuros proyectos (¡y te lo recomiendo!), asegúrate de realizar un **Fork** de este repositorio en tu propia cuenta de GitHub.

### Pasos para hacer el Fork:

1. Haz clic en el botón **Fork** en la esquina superior derecha de esta página.
2. Selecciona tu cuenta personal.
3. ¡Listo! Ahora tienes una copia exacta en tu perfil que no desaparecerá cuando este repositorio sea eliminado.
